# Demo video script (≤ 3:00)

Record on a phone-sized browser window (390 px wide) or a real phone with screen recording.

| Time | On screen | Voice-over |
|---|---|---|
| 0:00–0:20 | A real light bill held up to the camera (blur the name/address). Zoom on "Estimated" and "Band A". | "In Nigeria there's a name for this: crazy bills. Estimated bills, Band A prices for light you barely get, tokens that don't add up. NERC has rules for all of it — but who knows them?" |
| 0:20–0:35 | CrazyBill home screen. Tap **Take photo** (or the estimated-bill sample). | "CrazyBill: snap your light bill, find the overcharge, send the complaint." |
| 0:35–0:55 | Questions screen while "Reading your photo with Nemotron…" spins. Set DisCo, slide hours to 9, enter 21 days, pick "No meter". | "While NVIDIA Nemotron reads the photo, I answer three questions — my DisCo, how many hours of light I've actually had, and for how long." |
| 0:55–1:05 | Review screen. Point at an amber "check this" field and fix it. | "Every field is editable. Anything the model wasn't sure about is flagged." |
| 1:05–1:25 | Auditing screen: live list of Tavily searches — "Searching nerc.gov.ng…", "Reading …". | "Now a Nemotron 3 Ultra agent researches the current NERC tariff, band hours and complaint rules — live, with Tavily. You can watch every search." |
| 1:25–1:45 | Results: verdict banner with the red ₦ figure, then the breakdown formulas, then a finding with its source chip. Tap **WhatsApp**. | "Likely overcharged — and here's exactly how much, with the formula for every naira and a link for every rule. One tap to share in Pidgin, and a formal complaint letter is ready to send." |
| 1:45–2:05 | Open the **Model trace** panel. | "Under the hood: all inference runs on Nebius Token Factory. Super VL reads, Ultra researches once per audit, Lightning writes. The whole audit costs about `[$x]`." |
| 2:05–2:20 | Sources list ("Every link below was actually retrieved by Tavily"). | "Every source shown was really retrieved by Tavily in this run — if the model cites anything else, our source registry strips it." |
| 2:20–2:30 | Code: `src/lib/overcharge.ts` briefly. | "And the AI never does the money maths. Code does." |
| 2:30–3:00 | Back to the home screen; repo URL and demo URL on screen. | "Millions of Nigerian households pay for light they don't get. CrazyBill gives them the rules, the number and the letter. Next: a WhatsApp bot to log supply hours daily, and feeder-level data from the crowd. Try it — link below." |
